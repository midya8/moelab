03 / THREE DIFFERENT THINGS CALLED BALANCE

A penalty is not a traffic guarantee

The unchanged original trainer uses the per-example concentration penalty, averaged here: E mean_rows sum_e p_e(x)². Earlier module prose described E sum_e mean_rows(p_e)² instead; that text is corrected in the source. These are different objectives. Their gap is E times the sum of gate-probability variances.

Switch's reference loss is different again: E sum_e f_e P_e, with hard dispatch fractions f and mean probabilities P. Values below omit the external weighting coefficient. The uniform-tie control has a loss of 1 under all three conventions while every row goes to expert 0. No capacity limits or token dropping are modeled here.

What this cannot tell you

Exact rational geometry is for the mathematical affine extension of the supplied binary64 model and endpoints. Original inference still uses rounded dot products, softmax and gate argmax. Near a tie, those computations can disagree with exact geometry; both are exposed rather than silently snapped together. Softmax may underflow and prediction values remain floating-point approximations.

The frozen model has linear experts and no transformer, token capacity, dropping, communication or measured serving cost. Crossing a seam is not automatically an error, and smoother soft evaluation is not automatically better: the original soft MSE is worse on this fixture. One input path is not a robustness or generalization benchmark. Standard routing, softmax and piecewise-affine geometry are attributed, not a new method.
